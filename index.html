Every decklist format says the same thing in a different language. Drop a .ydk, paste a ydke:// URI, or drop a registration .json. Passcodes are translated to Konami CardDatabaseId values (and back) using the YGOPRODeck card database. Everything runs in this page — nothing is uploaded anywhere.

  Lookup table & offline use
  

    
Every card this page resolves is kept in a local lookup table, so repeat conversions are instant and work offline. Export it once and you never need the network again — reimport it on another machine, or on a tournament laptop with no wifi.

    

      
      
      
      
      
      
    

    
“Load full card database” pulls every card in one request (tens of megabytes). You only need it if you convert JSON → YDK for cards you’ve never looked up before and the per-card lookup isn’t available.
